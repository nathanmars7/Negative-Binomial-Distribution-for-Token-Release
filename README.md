# Negative binomial distribution for token release

> **Archived learning exercise (2022).** Kept as-is; not maintained and not part of the current portfolio.

A modelling notebook (`Negative Binomial Distribution for Token Release .ipynb`): visualise the growth of a social platform's user base over time, then estimate referral earnings in dollars for direct referrals and for the residual rewards that follow them, using a negative binomial distribution from SciPy and charts in seaborn.

## Run it

Open the notebook in Jupyter with `pandas`, `numpy`, `scipy`, `matplotlib` and `seaborn` installed.
